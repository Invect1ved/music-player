# Музыкальный плеер с визуализацией

Откройте `index.html` в браузере. Демо-файлы уже лежат в папке `audio` (WAV). Своё можно добавить кнопкой «Свой файл»: подходят MP3 и WAV.

На странице есть воспроизведение и пауза, перемотка, громкость, текущее время и длительность, список треков. Под панелью рисуются спектр и волна. На паузе столбики опускаются, при перемотке картинка идёт от новой позиции.

Плейлист можно сохранить под своим именем. Список хранится в браузере, добавленные файлы — в IndexedDB. Кнопки «Случайно» и «Повтор» включают случайный порядок и повтор всего списка или одного трека.

Пять демо-треков собраны программой из синусоидальных нот, это не чужие записи: Рассвет, Дождь, Город, Космос, Финал.
